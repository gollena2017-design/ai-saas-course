# Помилка 1

Команда запуску:

```bash
python3 -m app.main
Текст помилки:
ModuleNotFoundError: No module named 'aiogram'
Головний рядок traceback:
ModuleNotFoundError: No module named 'aiogram'
Файл і номер рядка:
app/main.py, рядок 5
Моя гіпотеза:
Пакет aiogram не встановлений у поточному Python-середовищі.
Причина помилки:
Python не зміг імпортувати aiogram, тому що залежність була недоступна в активному середовищі.
Як я виправила проблему:
Встановила залежності проєкту / активував середовище, де aiogram уже встановлений.
Який prompt передав AI:
Проаналізуй traceback.
Назви файл, рядок і тип помилки.
Запропонуй мінімальне виправлення.
Не змінюй зайві файли.
Як перевірив результат:
Повторно запустив:
python3 -m app.main
Бот успішно стартував і в logs зʼявилось:
INFO | bot started
INFO | Start polling

# Помилка 2

Команда запуску:

```bash
BOT_TOKEN="" python3 -m app.main
Текст помилки:
RuntimeError: Задайте BOT_TOKEN у файлі .env
Головний рядок traceback:
RuntimeError: Задайте BOT_TOKEN у файлі .env
Файл і номер рядка:
app/main.py, рядок 50
Моя гіпотеза:
Змінна середовища BOT_TOKEN порожня або не завантажилась.
Причина помилки:
Бот не може стартувати без Telegram token. У коді є перевірка:
if not token:
    raise RuntimeError("Задайте BOT_TOKEN у файлі .env")
Як я виправила проблему:
Переконалася, що у локальному .env є коректне значення BOT_TOKEN, і запустила застосунок звичайною командою.
Який prompt передав AI:
Проаналізуй traceback.
Спочатку назви файл, рядок і тип помилки.
Поясни причину простими словами.
Запропонуй мінімальне виправлення.
Не змінюй структуру проєкту.
Як перевірив результат:
Запустила:
python3 -m app.main
Бот успішно стартував, і в logs зʼявилось:
INFO | bot started
INFO | Start polling
