# Архітектура навчального продукту

## Назва та мета продукту

Навчальний продукт — Telegram-бот, створений на Python з використанням бібліотеки aiogram.

Мета продукту — дати користувачу можливість взаємодіяти з ботом через команди та отримувати відповіді безпосередньо в Telegram.

## Frontend

Frontend нашого продукту — це інтерфейс Telegram.

Користувач взаємодіє з ботом через:

* команди;
* текстові повідомлення;
* кнопки;
* відповіді бота.

Окремого веб-інтерфейсу в поточній версії проєкту немає.

## Backend

Backend реалізований на Python з використанням бібліотеки aiogram.

Backend:

* отримує повідомлення користувача;
* визначає, яку команду було надіслано;
* запускає відповідний обробник;
* виконує необхідну логіку;
* формує відповідь;
* передає відповідь користувачу через Telegram Bot API.

Основна логіка бота знаходиться у Python-файлах проєкту, зокрема в обробниках команд.

## Database

На поточному етапі база даних у проєкті не використовується.

У майбутньому база даних може використовуватися для збереження:

* користувачів;
* налаштувань;
* історії дій;
* операцій користувача;
* інших даних, які повинні зберігатися між запусками бота.

База даних є запланованим блоком, а не вже реалізованою частиною продукту.

## API

Для взаємодії між нашим застосунком і Telegram використовується Telegram Bot API.

Користувач надсилає повідомлення у Telegram, Telegram Bot API передає його backend-застосунку, а після обробки backend через той самий API надсилає відповідь назад у Telegram.

## Приклад роботи команди /start

1. Користувач надсилає команду `/start` у Telegram.
2. Telegram передає повідомлення нашому застосунку через Telegram Bot API.
3. Бібліотека aiogram визначає, який обробник відповідає за команду `/start`.
4. Python-код виконує логіку обробника.
5. Backend формує текст відповіді.
6. Відповідь передається через Telegram Bot API.
7. Користувач бачить повідомлення бота у Telegram.

Для виконання цієї команди база даних не потрібна.

## Майбутній розвиток

У майбутньому продукт можна розширити.

### Database

Можна підключити базу даних для збереження інформації про користувачів, їхні дії, налаштування та інші дані.

### AI

AI-модель можна підключити як окремий сервіс.

Backend зможе передавати AI-моделі дані через API та отримувати:

* пояснення;
* рекомендації;
* класифікацію інформації;
* автоматично сформовані звіти.

На поточному етапі AI описується як можливий майбутній блок, якщо він ще не підключений до проєкту.

# Розбір функцій реальних застосунків

## 1. Telegram — надсилання повідомлення

**Застосунок:** Telegram

**Функція:** Надсилання повідомлення

**Що робить користувач:**
Вводить текст у чаті та натискає кнопку надсилання.

**Frontend:**
Показує чат, поле введення повідомлення та кнопку надсилання.

**API:**
Передає повідомлення між клієнтським застосунком і серверною частиною Telegram.

**Backend:**
Обробляє повідомлення, визначає отримувача та організовує його доставку.

**Database:**
Зберігає дані, необхідні для роботи чатів та історії повідомлень.

**Результат:**
Користувач бачить своє повідомлення у чаті, а отримувач отримує його.

## 2. Банківський застосунок — перегляд балансу

**Застосунок:** Банківський мобільний застосунок

**Функція:** Перегляд балансу

**Що робить користувач:**
Відкриває застосунок і переходить до свого рахунку.

**Frontend:**
Показує список рахунків та поточний баланс.

**API:**
Передає запит від мобільного застосунку до backend банку.

**Backend:**
Перевіряє користувача та запитує актуальні дані рахунку.

**Database:**
Зберігає інформацію про рахунки та операції.

**Результат:**
Користувач бачить актуальний баланс свого рахунку.

## 3. Trello — створення задачі

**Застосунок:** Trello

**Функція:** Створення нової картки

**Що робить користувач:**
Вводить назву задачі та створює картку на дошці.

**Frontend:**
Показує дошку, списки, картки та форму створення нової картки.

**API:**
Передає дані нової картки до backend.

**Backend:**
Перевіряє отримані дані та створює нову картку.

**Database:**
Зберігає картки, дошки, списки та пов’язані з ними дані.

**Результат:**
Нова картка з’являється на дошці користувача.

## 4. YouTube — пошук відео

**Застосунок:** YouTube

**Функція:** Пошук відео

**Що робить користувач:**
Вводить пошуковий запит і запускає пошук.

**Frontend:**
Показує поле пошуку та список знайдених відео.

**API:**
Передає пошуковий запит до backend.

**Backend:**
Обробляє запит і знаходить відповідні результати.

**Database:**
Містить інформацію, необхідну для пошуку відео та формування результатів.

**Результат:**
Користувач отримує список відео, які відповідають його запиту.
